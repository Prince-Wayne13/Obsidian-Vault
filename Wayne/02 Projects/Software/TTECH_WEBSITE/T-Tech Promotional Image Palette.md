# T-Tech Promotional Image Palette

Palette extracted from the T-Tech Suppliers & General Dealers Ltd. promotional image. These values describe that image and are a reference for the T-Tech website’s visual direction.

| Swatch name | HEX | RGB | Role in image |
| --- | --- | --- | --- |
| Deep Teal Navy | `#246792` | `36, 103, 146` | Primary fill for the bottom contact/location bar and the “What We Offer” card |
| Brand Blue-Teal | `#3D7391` | `61, 115, 145` | “It’s Monday” headline and core brand blue tones |
| Logo Accent Blue | `#2D688C` | `45, 104, 140` | Top-left emblem/icon accent |
| Bright Teal Badge | `#4893A8` | `72, 147, 168` | “Premium Quality” callout pill |
| Charcoal Black | `#0C1A1E` | `12, 26, 30` | Company wordmark (“T-TECH SUPPLIERS & GENERAL DEALERS LTD”) and secondary text |
| Soft Ice Tint | `#C7EAF1` | `199, 234, 241` | Light background wash and subtle wave patterns |
| Mint Aqua | `#8FCEC9` | `143, 206, 201` | Secondary photo accent (phone case) |

## Use

Treat these as image-derived reference colors. Confirm them against the source artwork before adopting them as formal website design tokens.
