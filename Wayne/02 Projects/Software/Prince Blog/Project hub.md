# Prince Blog — Project hub

## Goal

Build a personal journal-portfolio space that shows what I do, learn, enjoy, and think about. It should feel personal and playful, not like a teaching platform or social-media feed.

## Done when

- The first version has a clear public portfolio, private journal, learning log, goals, and productivity calendar.
- The visual direction is decided and represented in a small working prototype.
- Community features are explicitly separated into later phases.

## Next action

- [ ] Reduce the idea to a first release: About, Portfolio, Journal, Learning Log, Goals, and Calendar.
- [ ] Write a one-page MVP brief before designing community, rooms, maps, or games.

## Current scope

### MVP

- Personal profile and portfolio
- Learning and project entries
- Goals with progress
- Productivity calendar
- Public/member/private visibility

### Later

- Community posts and comments
- Weekly picture wall
- Short private rooms
- Maps, intersections, games, and 3D presentation
