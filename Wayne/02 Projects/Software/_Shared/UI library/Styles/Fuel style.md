# Fuel style

## Feel
Clean, bold, friendly. (draft, edit me)

## Colors
| Name | Hex | Used for |
|---|---|---|
| Primary | #1F9AA8 | Accents, links, active states |
| Ink | #0F1A1C | Primary buttons (black pill), headings |
| Background | #F5F8F8 | Page |
| Surface | #FFFFFF | Cards, nav pill |
| Text | #0F1A1C | Body text |
| Muted | #5E6B6E | Secondary text |
| Highlight | #F3C969 | Small warm accents, badges |
| Has fuel | #2E9E6B | Fuel status: available |
| Low | #E8A33D | Fuel status: running low |
| Out | #D64545 | Fuel status: none |
| Unknown | #9AA5A8 | Fuel status: not updated |

## Typography
- UI font: Inter
- Display font (hero headlines only): Bebas Neue, or any bold condensed face
- Sizes: hero 40 / heading 24 / subheading 18 / body 16 / small 13
- Weights: 400 body, 600 headings and buttons

## Spacing and shape
- Spacing scale: 4, 8, 16, 24, 40
- Buttons, nav, tags: fully rounded (pill)
- Cards: radius 16
- Inputs: radius 12
- Shadows: very soft, or none; separate with space, not borders

## Components
- Icons: outline only (Tabler or Lucide), 1.5px stroke, 20px
- Primary button: Ink pill, white text. Secondary: white pill with thin outline
- Icon buttons: small white circles
- Cards: white, rounded, one clear title, one key value
- Navigation: small centered pill bar at top (or bottom on mobile)
- Status badges: small pill with the status color and a one-word label
- Loading: gray skeleton blocks in the same layout
- Empty and error states: one icon, one sentence, one button

## Layout rules
Mobile first. Large headline, one clear action, content in cards below. Lots of whitespace.

## Writing style
Short, direct labels ("Post status", "Find fuel"). No jargon.
