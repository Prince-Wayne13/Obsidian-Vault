# Outlook

Your tag "outlook" reads as overall look and feel, so I filed this as a whole-page style reference rather than a component. It is a checkout page.

## 1. Checkout page (LINOGE)

![[outlook - font, structure, less roundy, feels like an agent movie.jpg|420]]

**What I love:** font, structure, less roundy, feels like an agent movie

**What it is:** A two-column checkout: information, delivery and payment on the left, a shopping bag and totals on the right, then a black footer with an oversized tagline.

**How it's built:** Warm taupe backdrop, off-white page, one very heavy extended uppercase headline (CHECKOUT) and everything else tiny and light. Inputs are underline-only with no boxes. Radio rows are separated by hairlines. Buttons have square corners. The footer is black with huge white uppercase type.

**Rule to reuse:** Use a heavy extended display face only for the page title and keep the rest small. Underline fields, square corners, no shadows. Black and off-white with one warm backdrop.
