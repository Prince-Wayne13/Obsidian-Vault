# Toast

Four toast types with matching outline, fill and text colour.

## 1. Four toast types

![[Toast - outline glow, perfect icon, muted colour fill.jpg|420]]

**What I love:** outline glow, perfect icon, muted colour fill

**What it is:** Successful (teal), warning (orange), error (pink-red) and info (blue) toasts, each one line with an X.

**How it's built:** Rounded rectangles with a pale tint fill, a 2px outline in the type colour and a faint glow. A small solid circle icon on the left and one line of text in the same hue. The close X is teal on all four.

**Rule to reuse:** Outline, fill tint, icon and text share one hue per type. Keep it to one line. Consider matching the X to each type's hue (my suggestion, not in the picture).
