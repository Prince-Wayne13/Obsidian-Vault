# Area landing page

Structure-only landing-page pattern. Use placeholders for all copy, logos, data, and imagery.

- Logo strip: short trust label followed by a wrapping row of neutral logo placeholders.
- Benefits: section eyebrow, headline, supporting sentence, then four equal benefit columns with icons and descriptions.
- Numbered list: two-column section with a headline and four numbered points beside a media placeholder.
- Comparison table: centered section intro followed by feature columns and row-level comparisons.
- Testimonial: media placeholder beside a large quote and role metadata.
- Steps: section headline, optional CTA, then three numbered process cards.
- CTA: centered headline, supporting sentence, and one primary pill action.
