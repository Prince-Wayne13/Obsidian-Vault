### Summary

| Topic                      | What you find                      | Big O describes                                 |
| -------------------------- | ---------------------------------- | ----------------------------------------------- |
| Roots                      | where f(x) = 0                     | how fast guesses converge (next)                |
| Interpolation              | a curve through data points        | error as spacing h shrinks, and cost as n grows |
| Differentiation            | a slope                            | error as h shrinks                              |
| Integration                | an area                            | error as h shrinks                              |
| Linear systems (iterative) | n unknowns at once                 | cost per round as n grows, plus convergence     |
| ODEs                       | a function from its rate of change | error as step h shrinks                         |
