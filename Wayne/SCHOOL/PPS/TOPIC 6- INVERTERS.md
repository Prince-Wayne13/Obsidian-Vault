##### Functions

2. Voltage frequency control ->Establishes AC wave form according to operating mode [[TOPIC 6- INVERTERS#Operating modes]].
3. Power control -> Controls active and reactive power
4. Grid synchronization ->Matches frequency and voltage
5. Protection -> Responds to over/under voltage and other faults
6. Monitoring -> Energy data  
7. Battery interface ->
8. backup -> Instead of Grid- supply directly to loads

#### Operating modes
1. Grid following - synchronises with grid- voltage and frequeny has a grid refernce
2. Grid forming - sets up the reference for an isolated grid..with no grid reference
3. EPS/backup - Supplied loads with power when Grid fails
4. Battery interface - bidirectional , charges battery using grid AC power and Load power supply
